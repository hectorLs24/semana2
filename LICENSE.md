
# MODO EXAMEN

Modo Examen es una aplicación web creada para mantener al usuario concentrado en una sola tarea y registrar cuántas veces intenta salir de ella. El proyecto está pensado principalmente para estudiantes que necesitan realizar una actividad o examen sin distraerse.

El funcionamiento del proyecto es sencillo. Primero, el usuario inicia el modo examen y la aplicación muestra la tarea que debe realizar. Mientras la actividad está activa, el sistema controla los intentos del usuario de abandonar o cambiar de la página. Cada vez que se detecta un intento de salir, el contador aumenta. El usuario puede regresar y continuar con la actividad hasta finalizarla.

Al terminar el examen, la aplicación muestra el resultado de la actividad junto con la cantidad de veces que el usuario intentó escapar. De esta manera, el proyecto permite observar tanto la finalización de la tarea como el número de intentos de abandonar la actividad.

El proyecto fue desarrollado utilizando tecnologías web como HTML, CSS y TypeScript, utilizando Vite para la creación y ejecución de la aplicación y Vitest para realizar las pruebas de funcionamiento. También se utilizó Git y GitHub para llevar el control de versiones y publicar el proyecto.

La aplicación cuenta con una interfaz sencilla y adaptable a dispositivos móviles. Puede utilizarse mediante teclado o mediante la pantalla táctil de un teléfono. Se buscó que los botones fueran fáciles de utilizar y que el contenido pudiera visualizarse correctamente sin necesidad de desplazamiento horizontal.

El objetivo principal del proyecto es demostrar cómo una aplicación web puede controlar el estado de una actividad, registrar determinadas acciones del usuario y mostrar un resultado al finalizar. También permite poner en práctica la separación entre la lógica del programa y la interfaz visual, además de realizar pruebas para comprobar que las reglas principales funcionen correctamente.

El proyecto no incluye cuentas de usuarios, bases de datos, servidores propios, múltiples exámenes ni sistemas avanzados de calificación, ya que estas funciones quedan fuera del alcance establecido para esta práctica. El proyecto se concentra únicamente en el modo examen, la tarea principal y el registro de los intentos de salida.

El criterio para considerar que el proyecto funciona correctamente es que el usuario pueda iniciar el modo examen, realizar la tarea, intentar salir de la actividad, regresar y continuar, comprobar que el contador de intentos aumentó y finalmente terminar la actividad observando el resultado.

El proyecto fue realizado como parte de una práctica académica. Se utilizó una herramienta de inteligencia artificial como apoyo para generar parte del código, pero el desarrollo se realizó siguiendo las indicaciones y decisiones establecidas por el estudiante. El estudiante debe conocer y poder explicar el funcionamiento de las partes principales del proyecto, especialmente la lógica, el contador de intentos, las pruebas, la interfaz y el funcionamiento en dispositivos móviles.
